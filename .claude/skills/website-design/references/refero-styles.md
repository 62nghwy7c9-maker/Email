# Refero style catalog

200 styles from <https://styles.refero.design> (240 entries — some appear in two
collections), grouped by the collection they appear in.
Each entry links to a page that publishes a full DESIGN.md (colors, type scale, spacing,
radii, shadows, components, do/don't, imagery notes).

Pull one with:

```bash
python3 scripts/refero_style.py get "<name>" -o design/DESIGN.md
```

The full library is larger than this list (1,200+ styles). If nothing here fits, browse
<https://styles.refero.design> and pass the style URL to `get` instead.
